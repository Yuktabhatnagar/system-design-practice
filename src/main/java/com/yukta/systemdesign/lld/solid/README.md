# SOLID Principles

Examples for the five SOLID principles:

- `srp`: Single Responsibility Principle
- `ocp`: Open/Closed Principle
- `lsp`: Liskov Substitution Principle
- `isp`: Interface Segregation Principle
- `dip`: Dependency Inversion Principle

Use these examples before studying design patterns. Most patterns become easier to reason about once the dependency direction, abstraction boundaries, and class responsibilities are clear.
