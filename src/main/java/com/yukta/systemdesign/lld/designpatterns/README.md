# Design Patterns

Examples are grouped by standard pattern category:

- `creational`: object creation patterns such as factory, abstract factory, builder, prototype, singleton, and object pool
- `structural`: object composition patterns such as adapter, bridge, composite, decorator, facade, flyweight, and proxy
- `behavioural`: object interaction patterns such as chain of responsibility, command, iterator, mediator, memento, null object, observer, state, strategy, template, and visitor

Most packages contain a simple demo class and, where useful, a `Without...` version to show the problem before applying the pattern.
